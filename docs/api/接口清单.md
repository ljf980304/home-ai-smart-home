# 接口契约清单

dashboard 前端的数据契约。用于 **APIfox 建工程**（接口路径、字段、响应示例以下方为准），并在仓库 git 留档。

> 前端请求统一带 `/api` 前缀（如 `GET /api/devices`），由 vite proxy 重写为下方路径后转发到 APIfox mock / 真实后端。**本清单中的路径均不含 `/api` 前缀。**

## 数据模型

### Device（设备）

按类型判别的联合：公共属性 + 各类型专属的 `state`。`type` 决定 `state` 的形态（灯/空调/风扇），switch/curtain/sensor/plug 暂无专属状态。

```ts
type DeviceType =
  | 'light' | 'switch' | 'air-conditioner' | 'curtain'
  | 'sensor' | 'plug' | 'fan'

interface DeviceBase {
  id: string
  name: string
  type: DeviceType
  room: string          // 所属房间，如 '客厅'、'主卧'
  online: boolean
  power: boolean
}

interface LightState {
  brightness: number    // 亮度 0-100
  colorTemp: number     // 色温 2700-6500 K
}

interface AirConditionerState {
  temperature: number   // 温度设置 ℃
}

interface FanState {
  windLevel: 1 | 2 | 3 | 4         // 风量挡位
  mode: 'direct' | 'natural'       // 直吹 / 自然风
  swingH: boolean                  // 左右摇头
  swingHAngle: 30 | 60 | 90 | 120  // 左右摇头角度（度）
  swingV: boolean                  // 上下摇头
  swingVAngle: 30 | 60 | 90 | 100  // 上下摇头角度（度）
  timerHours: 0 | 1 | 2 | 3 | 4    // 定时待机（小时，0 = 关闭）
}

type Device =
  | (DeviceBase & { type: 'light'; state: LightState })
  | (DeviceBase & { type: 'air-conditioner'; state: AirConditionerState })
  | (DeviceBase & { type: 'fan'; state: FanState })
  | (DeviceBase & { type: 'switch' | 'curtain' | 'sensor' | 'plug' })
```

### Scene（场景）

```ts
interface Scene {
  id: string
  name: string
  description?: string
  enabled: boolean
  createdAt?: string    // ISO 时间
}
```

## 设备接口

### `GET /devices` — 设备列表

响应：`Device[]`

```json
[
  {
    "id": "light-001",
    "name": "客厅吸顶灯",
    "type": "light",
    "room": "客厅",
    "online": true,
    "power": true,
    "state": { "brightness": 80, "colorTemp": 4000 }
  }
]
```

### `PATCH /devices/:id` — 设备控制

请求体为要更新的字段（公共字段直接平铺，类型专属字段放在 `state` 内）：

```json
{ "power": false }
```

```json
{ "state": { "brightness": 60 } }
```

```json
{ "state": { "colorTemp": 5000 } }
```

```json
{ "state": { "windLevel": 2 } }
```

```json
{ "state": { "mode": "natural" } }
```

```json
{ "state": { "swingH": true, "swingHAngle": 90 } }
```

响应：更新后的 `Device`。

## 场景接口

### `GET /scenes` — 场景列表

响应：`Scene[]`

### `POST /scenes` — 创建场景

请求体：

```json
{ "name": "回家模式", "description": "开灯、开空调、关窗帘" }
```

响应：新建的 `Scene`（含服务端生成的 `id`）。

### `DELETE /scenes/:id` — 删除场景

响应：`204 No Content`。

### `PATCH /scenes/:id` — 更新场景

请求体：

```json
{ "enabled": false }
```

响应：更新后的 `Scene`。
